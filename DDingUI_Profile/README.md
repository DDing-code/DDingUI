# DDingUI Profile

All-in-one UI profile installer for World of Warcraft. Configure six supported addons through one guided setup.

## Supported Addons

| Addon | Description |
| --- | --- |
| **BigWigs** | Boss bar and alert settings |
| **DDingUI CDM** | Per-specialization cooldown manager layouts |
| **DDingUI Toolkit** | DDingUI utility module settings |
| **EllesmereUI** | UI addon profile |
| **WarpDeplete** | Mythic+ timer layout |
| **Platynator** | Nameplate profile and style |

## Features

- **8-Step Install Wizard** - Guided setup from welcome to completion
- **Standalone or ElvUI Integration** - Uses its own installer UI, or ElvUI's PluginInstaller when ElvUI is loaded
- **One-Click Apply** - Apply each installed addon's profile with a single button
- **Per-Spec Cooldowns** - Built-in DDingUI CDM layouts for every specialization
- **Profile Reuse** - Install once, then load saved profiles on alternate characters
- **Custom Media Included** - 4 fonts, 3 status bar textures, and 71 sound files
- **Addon Compartment Support** - Reopen the installer from WoW's addon compartment

## Slash Commands

- `/ddp` or `/ddp install` - Open the install wizard and show the current version
- `/ddp load` - Load saved profiles on the current character
- `/ddp reset` - Reset the installation state; use `/reload` before reinstalling

## Requirements

DDingUI Profile has no required external UI framework. ElvUI integration is optional.

Supported addons are optional and missing addons are skipped automatically:

- BigWigs
- DDingUI CDM
- DDingUI Toolkit
- EllesmereUI
- WarpDeplete
- Platynator

## Included Media

### Fonts (4)

- DDing Asia
- Gotham Narrow Ultra Asia
- Noto Sans JP Black
- SAO Welcome Bold

The included fonts support Korean, Chinese, Japanese, Russian, and other WoW client locales.

### Status Bar Textures (3)

- DDing Melli
- DDing BuiOnePixel
- DD SL Bracket

### Sounds (71)

Alert and effect sounds registered through LibSharedMedia for use with compatible addons.

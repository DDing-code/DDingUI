# Changelog

## 1.3.1 - 2026-08-09

### English

- Refreshed the installer with the latest DDingUI StyleLib layout and motion system.
- Streamlined the installer to the currently supported profile catalog and added direct import handlers.
- Added a red DDingUI Profile icon, wordmark, and title-bar branding.
- Added version output to `/ddp` and increased the wake-up alert volume.
- Refreshed the bundled DDingUI CDM profile data and distribution description.

### 한국어

- 설치 화면을 최신 DDingUI StyleLib 레이아웃과 모션 시스템에 맞춰 개편했습니다.
- 설치 목록을 현재 지원하는 프로필로 정리하고 직접 가져오기 처리를 추가했습니다.
- 빨간색 DDingUI Profile 아이콘, 워드마크, 제목바 브랜딩을 추가했습니다.
- `/ddp` 실행 시 버전을 표시하고 기상 알림음 음량을 높였습니다.
- 내장 DDingUI CDM 프로필 데이터와 배포 설명을 최신 상태로 갱신했습니다.

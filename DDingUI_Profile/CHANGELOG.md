# Changelog

## 2.1 - 2026-08-24

### English

- Added Japanese voice alerts for Bloodlust ready, available, activation, and ending states.
- Added Japanese voice alerts for combat start, combat end, party full, and group application events.
- Added Japanese voice alerts for Time Spiral, Power Infusion, and Spatial Paradox.
- Matched all new voice alerts to the boosted stereo loudness of the existing DDingUI alert set.
- Expanded the LibSharedMedia sound catalog to 74 registered sounds.

### 한국어

- 블러드러스트 준비, 사용 가능, 활성화 및 종료 상태를 안내하는 일본어 음성 알림을 추가했습니다.
- 전투 시작, 전투 종료, 파티 모집 완료 및 파티 신청을 안내하는 일본어 음성 알림을 추가했습니다.
- 시간의 와류, 마력 주입 및 공간의 역설을 안내하는 일본어 음성 알림을 추가했습니다.
- 새 음성 알림의 스테레오 체감 음량을 기존 DDingUI 알림음과 동일한 수준으로 맞췄습니다.
- LibSharedMedia 사운드 목록을 총 74개로 확장했습니다.

## 1.3.1 - 2026-08-09

### English

- Refreshed the installer with the latest DDingUI StyleLib layout and motion system.
- Streamlined the installer to the currently supported profile catalog and added direct import handlers.
- Added a red DDingUI Profile icon, wordmark, and title-bar branding.
- Added version output to `/ddp` and increased the wake-up alert volume.
- Refreshed the bundled DDingUI CDM profile data and distribution description.

### 한국어

- 설치 화면을 최신 DDingUI StyleLib 레이아웃과 모션 시스템에 맞춰 개편했습니다.
- 설치 목록을 현재 지원하는 프로필로 정리하고 직접 가져오기 처리를 추가했습니다.
- 빨간색 DDingUI Profile 아이콘, 워드마크, 제목바 브랜딩을 추가했습니다.
- `/ddp` 실행 시 버전을 표시하고 기상 알림음 음량을 높였습니다.
- 내장 DDingUI CDM 프로필 데이터와 배포 설명을 최신 상태로 갱신했습니다.

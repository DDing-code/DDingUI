# DDingUI_FX 2.2.0

스킬 시전 시작 / 사용 성공 직후 / 내 버프 활성화에 제작된 TGA 애니메이션과 효과음을 연결합니다.
사용자가 제작을 요청한 **허식 · 무라사키** TGA 효과를 포함합니다.

FX 컨셉 컬러는 **코발트 블루 #4D8DFF**입니다. 공통 DDingUI 로고와 제목줄 검색·GUI 크기·편집 모드 배치를 사용합니다.

## 사용

1. 미니맵 버튼 좌클릭 또는 `/dfx`, `/ddingfx`로 설정을 엽니다. `/dfx edit`는 편집 모드를 켜고 끕니다.
2. 스킬 목록의 **+ 스킬 추가** 행을 클릭하고 스킬 이름 또는 ID를 입력합니다. 입력칸 아래 자동완성 목록에서 아이콘·이름·ID를 확인하고 클릭하거나 ↑↓와 Enter/Tab으로 선택합니다. Esc는 입력을 취소합니다.
3. **스킬 / 버프**와 발동 조건을 선택하고, 검색형 효과음 목록과 모션 프리셋을 고릅니다.
4. 프리셋에 마우스를 올리면 무음으로 반복 재생되는 미리보기가 표시됩니다. 마우스를 떼면 끝납니다.
5. 제목줄 **편집 모드**에서 위치·크기·투명도·속도를 조절합니다. **실제 화면 테스트**를 누르면 설정창이 닫히고 게임 화면에서 모션과 소리가 한 번 재생된 뒤 설정창이 다시 열립니다.

옵션 선택은 즉시 적용됩니다. 텍스트 입력은 Enter 또는 다른 항목 클릭으로 완료되며 자동 저장됩니다.
설정창을 닫거나 다른 스킬을 고를 때도 입력을 완료합니다. 잘못된 입력이나 전투·제한 상태에서 변경한 값은 적용하지 않고 원래 값으로 돌아갑니다.
스킬을 삭제하려면 해당 목록 행 오른쪽의 **X**를 누릅니다. 검색된 목록에서도 해당 스킬만 삭제됩니다.
스킬 설정은 **캐릭터의 전문화별로 최대 128개** 저장하며, 전문화를 바꾸면 해당 목록으로 자동 전환합니다. 목록 제목에 현재 전문화를 표시합니다.
기존 캐릭터 공용 설정은 업데이트 후 처음 확인된 전문화에 보존하고, 다른 전문화는 빈 목록으로 시작합니다. 전문화 정보가 아직 준비되지 않았다면 기존 설정을 보존한 채 확인을 기다립니다.
모션·효과음 프리셋과 미니맵 위치는 전문화 간 공유합니다. 빈 추가 행은 이름/ID를 입력하기 전까지 저장하지 않습니다.
자동완성은 내 스킬북과 이미 등록한 주문을 검색하며 상위 8개를 표시합니다. 결과가 많으면 이름을 더 입력하세요.
스킬북에 없는 버프 등은 정확한 이름이나 주문 ID를 직접 입력할 수 있습니다.

- 실제 발동은 한 번 재생하며, 같은 항목이 다시 발동하면 첫 프레임부터 다시 시작합니다. 다른 항목은 함께 재생할 수 있습니다.
- 시전 시작에는 채널링·강화 시전 시작도 포함합니다. 즉시 시전 주문은 **사용 성공 직후**를 사용하세요.
- 효과음은 설치된 SharedMedia 제공 애드온의 등록된 소리를 검색하고 미리 들을 수 있습니다. 모션과 소리 각각 **없음**을 선택할 수 있습니다.
- 위치 X/Y는 화면 중앙 기준이며 양수는 오른쪽/위쪽입니다. **크기 (%)** 슬라이더 또는 숫자로 10~400%를 조절하며 가로·세로 비율을 유지합니다. 새 효과의 100%는 256×256이며, 기존에 저장한 가로·세로 크기는 100% 기준으로 보존합니다. 속도는 배율입니다.

## 편집 모드와 미니맵

스킬을 선택한 뒤 설정창 제목줄의 **편집 모드** 버튼(편집 중에는 **편집 중**), 미니맵 버튼 우클릭 또는 `/dfx edit`로 효과 위치를 직접 편집합니다.
설정창 대신 실제 화면에 선택 영역(모서리 꺾쇠)·중심 십자선·`X Y · 가로×세로` 표시와 시리즈 공통 편집 리모컨이 나타납니다.
영역을 드래그하면 위치가 바뀌며, 리모컨의 X/Y 입력·▲▼◀▶ 버튼·키보드 방향키(1px, Shift 10px)로 조절할 수 있습니다.
리모컨 선택 정보에 기준(화면 중앙)·크기 %·실제 가로×세로를 표시합니다. 리모컨 제목줄을 끌어 옮긴 위치는 캐릭터별로 저장됩니다.
리모컨 아래 **효과 미리보기** 구역에서 **현재 전문화에 등록한 모든 스킬·버프 효과**를 검색·선택할 수 있습니다. 스킬 이름·ID·발동 조건·모션 이름으로 검색하며, 다른 효과를 고르면 해당 위치·크기·투명도·속도를 불러옵니다. 전환 전에 입력하던 값은 원래 효과에 저장됩니다.
같은 구역에 스킬 아이콘·현재 전문화·모션과 크기 (%)·투명도 (%)·재생 속도 슬라이더, **중앙으로** 버튼이 있습니다.
편집 중 전문화를 바꾸면 편집을 종료하고 새 전문화의 설정 목록을 엽니다. 이전 전문화의 미리보기·실제 화면 재생을 정리하고 버프 효과음 등록도 새 목록으로 갱신합니다.
진입 시 화면 중앙 기준 격자(기본 32, **간격** 버튼으로 16/32/64)가 나타납니다. **스냅**·**중앙**·**격자** 체크로 8px 이내 정렬을 켜고 끄며, 드래그 중 안내선을 표시하고 Shift를 누르면 스냅을 잠시 해제합니다. FX는 다른 편집 대상이 없어 **프레임** 스냅 체크가 없습니다.
**실행 취소**(Ctrl+Z)·**다시 실행**(Ctrl+Y)은 현재 효과의 변경을 되돌리며, **초기화**는 위치 0,0 · 크기 100% · 투명도 100% · 속도 1로 되돌립니다.
제작된 모션이 있으면 무음으로 반복 표시하며, 모션이 없어도 선택 영역으로 위치와 크기를 조절할 수 있습니다.
드래그 완료와 입력 완료 시 자동 적용됩니다. **완료**로 설정에 돌아오거나 Esc로 종료하세요.
전투·제한 상태 진입 시 편집을 종료하며, 끝내지 않은 드래그는 저장하지 않습니다.

미니맵 버튼은 좌클릭으로 설정 열기/닫기, 우클릭으로 편집 모드 전환, 드래그로 위치 이동합니다.
버튼 위치는 캐릭터별로 저장됩니다. 로고 파일을 추가한 이번 변경 후에는 게임을 완전히 종료하고 다시 실행하세요.

## 제작된 모션 추가

**허식 · 무라사키**: 적색·청색 구체 융합 → 보라색 핵과 전격 → 방출 → 갈라지는 잔광 소멸.
`Media/HollowPurple.tga`는 4096×4096, 32비트 알파, 8열×8행, 512×512 셀의 실제 연속 그림48개,24 FPS(2초)입니다. v3는 밝은 전격 대신 구체 외곽으로 확인한 기준점으로 정렬해 위치 흔들림을 보정했습니다.
참고 GIF의 흐름을 바탕으로 새로 생성한 효과이며 캐릭터 영상은 포함하지 않습니다.
각 셀에는 인접 프레임이 섞이지 않도록 최소32px 투명 여백이 있습니다. 마지막16칸은 사용하지 않습니다.
새 미디어 파일이므로 게임을 완전히 종료한 뒤 재실행하고 해당 프리셋을 선택하세요.

게임 안의 TGA 등록 화면은 없습니다. 제작한 TGA는 `Media` 폴더에 넣고 `Presets.lua`의 목록에 연결합니다.
필요한 항목과 예시는 [Media/README.md](Media/README.md)에 있습니다. 애드온은 디스크 폴더를 자동 검색하지 않습니다.
이전 초기 버전에서 저장한 프리셋 연결은 보존합니다. 새로 배포하는 프리셋 정보는 애드온 내부 목록에서 읽습니다.
새 TGA 파일을 넣었다면 게임을 완전히 종료하고 다시 실행하세요.

## 버프 지원 범위

버프 소리는 `C_UnitAuras.AddAuraSound`의 Added 이벤트에 등록합니다. 설정 변경은 전투·API 제한 해제 후 가능합니다.
버프 모션은 **공개된 버프의 비활성 → 활성 전환**을 감지할 때 재생합니다. 이미 존재하는 버프를 로그인·리로드·설정 변경 때 새 발동으로 재생하지 않습니다.
전투 중 secret으로 제한되는 버프의 임의 TGA 1회 발동은 지원하지 않습니다. 이 경우 등록된 버프 효과음만 게임 API가 처리합니다.
버프 갱신·중첩 증가를 새 활성화로 취급하지 않습니다. 전투 로그나 숨겨진 값 추측을 사용하지 않습니다.

근거: [Blizzard aura API](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitAuraDocumentation.lua),
[주문별 제한 판정](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/SecretPredicateAPIDocumentation.lua).

## 검증과 재사용

`python DDingUI_FX/tests/test_fx.py`

설치된 `lupa.lua51`로 실제 TOC·라이브러리·UI·재생·이벤트 코드를 실행합니다. 자동 저장과 잘못된 입력 복구,
목록 추가/검색/삭제, 전문화별 기존 설정 이관·전환·재로드, 편집 미리보기 선택과 입력 보존, 미리 듣기, 호버 미리보기 종료, 실제 화면 테스트, 시전/버프 전환, 전투 변경 차단을 확인합니다.
실제 WoW 렌더링·TGA 디코딩·소리·taint는 인게임 확인이 필요합니다.

현재 Toolkit에 포함된 StyleLib를 `DDingUI-FX-StyleLib-1.0`으로 임베드하여 기존 애드온의 전역 스타일을 덮어쓰지 않습니다.
공통 제목줄과 Toolkit `UI/Controls.lua`, `UI/Dropdown.lua`의 입력·전환·슬라이더·검색형 미디어 위젯을 재사용합니다.
LibStub/CallbackHandler/LibSharedMedia를 포함하여 Toolkit 없이도 실행 가능합니다.
미니맵 버튼은 Toolkit에서 사용하는 LibDataBroker/LibDBIcon 사본을 포함합니다.
시리즈 제목은 `DDing` 흰색·`UI` 주황색(#FFA300)으로 고정하고, 뒤의 애드온 이름만 컨셉 색상 그라데이션을 사용합니다.
FX 설정창과 편집모드는 공통 StyleLib 제목을 사용하며, FX 이름에 코발트 블루 그라데이션을 적용합니다.
